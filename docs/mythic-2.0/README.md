# Mythic 2.0 — Preproduction Workspace

**Status:** Active first-principles rebaseline  
**Date:** 2026-08-24  
**Target:** Native Steam/desktop RPG built in Godot with an authoritative persistent server-side world simulation.

## Why this workspace exists

Mythic has crossed a product boundary. The original browser-first implementation and dashboard-oriented UX are no longer the correct implementation target. The project is now a native 2D RPG with tactical depth, unrestricted grounded player intent, persistent causal world simulation, generational continuity, and AI-mediated world/character agency.

This workspace does **not** discard the World Constitution, canon, rules research, Ledger Time, event-ledger principles, viewpoint-safe knowledge, RAG/content architecture, morality/progression concepts, or prior asset work. It supersedes the old player-client and product-presentation assumptions.
