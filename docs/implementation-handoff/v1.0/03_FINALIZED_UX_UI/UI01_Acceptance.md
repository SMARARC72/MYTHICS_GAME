## 2. Experience Demonstrated

The reference first viewport combines World Strip, Campaign Rail, Active Surface Header, Scene Frame, Context Lens, Exact Speech Block, Meaningful Markers and an interactive Intent Dock. A player may type a Goal and Method, choose non-exhaustive contextual possibilities, inspect the interpreted action and correct it. The surrounding interface reads as a living game world, not as a themed chatbot.

The component catalog is searchable and family-filterable. Selecting any component exposes its props, interactive states, responsive rule, accessibility semantics and contract boundary. Library-wide controls demonstrate compact density, 115% text, high contrast, reduced motion and alternate input.

All story data in the browser reference is illustrative and noncanonical. It exists only to prove composition and interaction behavior.

## 3. Binding Visual Foundation

- Quiet ink surfaces carry dense world information; warm gold marks player agency and commitment.
- Teal marks known or verified facts, orange marks pressure and violet marks uncertainty.
- Color never carries meaning alone; every semantic use has a visible word, shape or structural cue.
- Scene prose uses a measured serif voice, interface language uses a compact sans voice and Ledger facts use a mono voice.
- Minimum primary control target is 40px; visible focus is 2px with 3px offset.

The machine-readable token file is the implementation source for palette, type roles, spacing, geometry and focus values.

## 4. Semantic State Grammar

Every material component must account for loading, empty, stale, conflict, recovery and unavailable behavior. Those states name what happened, what remains trustworthy and the safest next action. They never infer success, invent permission, erase a player draft or silently retry an unknown commit.

## 5. Responsive Contract

Desktop browser is the reference density. At 980px, the World Strip wraps, the Campaign Rail becomes a labeled horizontal bar, the Context Lens moves below the Stage and the selected specimen moves above the catalog. At 720px, content becomes a single readable column and tabular structures become labeled rows. Recomposition may change emphasis but may not remove a core capability.

## 6. Accessibility Contract

The library defines semantic landmarks, visible focus, noncolor state cues, deduplicated live-region behavior, an Alternate Input Tray and motion substitutes. It supports 200% reflow, forced colors, reduced motion and keyboard-only use. Free text remains available; alternate input supplements it rather than narrowing legal intent.

## 7. Contract and Canon Boundary

Each component record carries its approved C4 contract IDs, payload boundary, fixtures/tests and authority/frontend owners. Components may own focus, reversible local drafts, presentation state and composition. They may not invent canonical state, hidden truth, permissions, actor motives, media approval or receipt outcomes.
